# Design: add-sensor-filtering-task

## 任务设计

### 情境

某化工厂的反应釜温度传感器采集数据包含噪声，且偶发异常尖峰。学习者需要设计滤波算法去除噪声，并检测异常数据点。

### 核心技能

1. **信号滤波**：移动平均、指数平滑、低通滤波
2. **异常检测**：统计方法（Z-score、IQR）、阈值检测
3. **数据可视化**：滤波前后对比、异常点标注

### 关联能力

| 能力 ID | 作用 |
|---------|------|
| `industrial-data-wrangling` | 数据加载、清洗、预处理 |
| `statistical-analysis` | 统计方法用于异常检测 |
| `simulation-validation` | 验证滤波算法效果 |

### 任务步骤

1. 加载传感器原始数据，观察噪声特征
2. 实现移动平均滤波，对比不同窗口大小效果
3. 实现指数平滑滤波，调整平滑系数
4. 设计低通滤波器，分析频域特性
5. 使用统计方法检测异常点（Z-score、IQR）
6. 设计阈值检测规则，处理连续异常
7. 可视化滤波前后对比和异常检测结果
8. 撰写分析报告

### 评价维度

| 维度 | 基础 | 合格 | 优秀 |
|------|------|------|------|
| 滤波算法实现 | 算法有明显错误 | 算法正确，参数合理 | 算法正确，参数优化有依据 |
| 异常检测方法 | 方法不当或遗漏 | 方法基本正确 | 方法恰当，误报率低 |
| 数据可视化 | 图表不完整 | 图表清晰 | 图表专业，对比充分 |
| 工程报告 | 报告缺失 | 报告完整 | 报告专业，结论可操作 |

### 预计耗时

6-8 小时
